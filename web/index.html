75 °C
ⓘ
Cooling: the override is applied once when a new game session is confirmed; saving does not change an active game immediately. Higher targets delay fan ramp-up and can increase console temperatures. Use only one payload to control this setting. Switching back to System stops future PrefBar writes; it does not restore a previous custom target.
